# Budget Tracker

Personal budget tracker pulling account data from US Bank, Discover, and Robinhood via Plaid,
plus manual entry for cash savings and anything Plaid can't reach. Runs locally on your home
network so it's reachable from both your phone and laptop.

Stack: FastAPI (backend) + React/Vite (frontend) + SQLite.
